### Bob · 0.0439 Bobcoins

All 24 tests pass. The root cause was a single inverted comparison operator on line 54 of [`flaskr/blog.py`](flaskr/blog.py:54):

**Before (buggy):**
```python
if check_author and post["author_id"] == g.user["id"]:
    abort(403)
```

**After (fixed):**
```python
if check_author and post["author_id"] != g.user["id"]:
    abort(403)
```

The condition was checking if the current user **is** the author and blocking them, when it should block access if the current user is **not** the author. This caused:
- The post owner to get 403 Forbidden (couldn't update/delete their own posts)
- Non-owners to get through the check and hit form validation errors instead of 403
