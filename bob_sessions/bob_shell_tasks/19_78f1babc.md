### What changed

**[`flaskr/blog.py`](flaskr/blog.py)**

**[`flaskr/__init__.py`](flaskr/__init__.py)**

**[`flaskr/templates/blog/index.html`](flaskr/templates/blog/index.html)**  
- Changed the body element from `<p class="body">{{ post['body'] }}</p>` to `<div class="body">{{ post['body'] | render_markdown | safe }}</div>`  
  - `| render_markdown` converts the Markdown text to an HTML string (raw HTML in the body is already escaped by `markdown-it-py` itself)  
  - `| safe` tells Jinja not to double-escape the resulting HTML tags that the Markdown renderer intentionally produced  
  - `<div>` instead of `<p>` because the rendered output is a block-level element that may contain nested `<p>`, `<ul>`, `<ol>`, etc. (a `<p>` wrapping another `<p>` is invalid HTML)
