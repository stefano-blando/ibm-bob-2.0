### Bob · 0.0484 Bobcoins

All 24 tests pass. The bug was a one-character typo in [`get_post()`](flaskr/blog.py:54) — the authorization guard had `==` where it needed `!=`:

```python
# Before (broken): aborts when user IS the author
if check_author and post["author_id"] == g.user["id"]:
    abort(403)

# After (correct): aborts when user is NOT the author
if check_author and post["author_id"] != g.user["id"]:
    abort(403)
```

This inverted condition caused every authorization check on posts to be backwards: the real author was forbidden from their own posts, while non-authors could modify anyone else's posts.
