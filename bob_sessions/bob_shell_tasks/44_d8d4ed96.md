Found it. The bug is on line 154 of [`app/models.py`](app/models.py:154):

```python
def is_following(self, user):
    query = self.following.select().where(User.id == user.id)
    return db.session.scalar(query) is None  # BUG: returns True when NOT following
```

The logic is inverted — `is None` means "no result found" (i.e. NOT following), so this returns `True` when the user is **not** following, and `False` when they are. It should be `is not None`.

This is the root cause of the cascade: `is_following` returns the wrong value, which makes `follow()` think u2 is already followed (so it never adds), and then `following_count()` returns 0.
