### What was done

**[`flaskr/__init__.py`](flaskr/__init__.py)**

- Imported `MarkdownIt` from `markdown-it-py` (already installed in `.venv`) and `Markup` from `markupsafe` (bundled with Flask).
- Created a module-level `_md` instance with the `html_block` and `html_inline` rules **disabled** — this causes any raw HTML written in a post body to be escaped (`<script>` → `&lt;script&gt;`) rather than passed through, preventing XSS injection.
- Registered a `markdown` Jinja2 filter via `app.jinja_env.filters` that calls `_render_markdown` and returns a `Markup` object, which Jinja2 treats as already-safe and won't double-escape.

**[`flaskr/templates/blog/index.html`](flaskr/templates/blog/index.html:22)**

- Changed `<p class="body">{{ post['body'] }}</p>` to `<div class="body">{{ post['body'] | markdown }}</div>`. The `| markdown` filter converts the body text to rendered HTML (`**bold**` → `<strong>bold</strong>`, etc.), and wrapping in a `<div>` (rather than `<p>`) allows block-level Markdown output like lists and headings to be nested correctly.
