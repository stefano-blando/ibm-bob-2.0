**Root cause:** In [`format_approx_duration()`](hc/lib/date.py:65), the condition on line 72 was `days != 1` instead of `days == 1`. This caused the function to:
1. Return `"1 day {hours} h"` for every case where `days ≠ 1` (including 0, 2, 3, …)
2. Never reach the `if days:` branch (it was dead code)

The one-character fix — `!=` → `==` — restores the correct logic:
- `days == 1` → singular `"1 day {hours} h"`
- `days > 1` → plural `"{days} days {hours} h"`
- `days == 0` → fall through to hours/minutes/seconds branches
