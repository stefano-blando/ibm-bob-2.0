All 4 tests pass. 

**Root cause:** [`is_following()`](app/models.py:152) had an inverted `None` check — `is None` instead of `is not None`. This single-character logical negation error corrupted the entire follow/unfollow system:

- `follow()` guards with `if not self.is_following(user)` — but since `is_following` returned `True` for users **not** in the list, `follow()` never actually added anyone
- `unfollow()` guards with `if self.is_following(user)` — symmetrically, it could only try to remove users that weren't there
- `following_posts()` then returned only the user's own posts (the `Author.id == self.id` branch) because no follows were stored

Fix: changed `is None` → `is not None` on line 154.
